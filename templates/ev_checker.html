What is Expected Value (EV)?
Edge compares model probability with the bookmaker's margin-adjusted implied probability. Expected ROI uses the actual bookmaker decimal price to estimate the return on a bet according to our model. Row highlights and value thresholds are based on Expected ROI, not Edge.

How is bookie probability calculated?
Bookmakers build a margin (overround) into their odds so that the implied probabilities across all outcomes add up to more than 100%. We strip that margin out to get a fair, margin-adjusted implied probability - giving a like-for-like comparison against our model.

How to read the table
Model % - our model's probability for that outcome.
Bookie % - the margin-adjusted implied probability from the bookmaker's odds.
Edge - model minus fair bookie probability, expressed in percentage points (pp).
Expected ROI - (model probability × median bookmaker decimal odds − 1) × 100. Uses actual odds without removing the bookmaker margin. Positive means a model-estimated profit per unit staked; negative means an expected loss. A dash means no valid price is available.

Value thresholds
Strong value (ROI >+10%) - model-estimated expected return above 10%.
Marginal (ROI >0% to +10%) - positive model-estimated expected return up to 10%.
No value (ROI ≤0%) - zero or negative expected return at the median quoted price. No highlight is applied where ROI is unavailable.

Important
Expected ROI is model-driven, not a guarantee of profit. Median recorded bookmaker prices may differ from odds actually available when placing a bet. Odds move constantly, and projections carry uncertainty. This is not betting advice. Gamble responsibly.
